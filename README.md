# 🌱 Energias no Campo

## 📋 Sobre o Projeto

Este projeto foi desenvolvido como parte do **Concurso Agrinho 2026**, com o tema **"Energias Renováveis no Campo"**.  
O site tem o objetivo de informar, conscientizar e incentivar o uso de energias limpas na agricultura, especialmente no Paraná.

O visual segue um estilo **Magazine Educacional** moderno, colorido e responsivo, ideal para estudantes, professores e produtores rurais.

---

## ✨ Funcionalidades

- **Design totalmente responsivo** (Mobile First)
- **Menu Hambúrguer** funcional na versão mobile
- **Dark Mode / Light Mode** com persistência no `localStorage`
- **Conteúdo dinâmico**: 8 notícias renderizadas via JavaScript
- **Filtro por categoria** (clicando nos cards de tipos de energia)
- **Scroll suave** entre seções
- **Animações** ao rolar a página (Intersection Observer)
- **Formulário de newsletter** com validação
- **Efeito de header** ao rolar a página
- **Acessibilidade** básica (aria labels, foco visível, etc)

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** Semântico
- **CSS3** Moderno (Flexbox + CSS Grid + Variáveis)
- **Vanilla JavaScript** (ES6+)
- Google Fonts (Playfair Display + Inter)
- Design responsivo sem frameworks
